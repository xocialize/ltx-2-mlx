# ltx-pipelines-mlx

Generation pipelines and the `ltx-2-mlx` CLI — T2V, I2V, A2V, retake, extend, keyframe, IC-LoRA, DFR.

Part of [**ltx-2-mlx**](https://github.com/xocialize/ltx-2-mlx) — a pure-MLX port of
[LTX-2](https://github.com/Lightricks/LTX-2) for Apple Silicon. See the
[repository README](https://github.com/xocialize/ltx-2-mlx#readme) for installation, quick start,
and the CLI reference.
